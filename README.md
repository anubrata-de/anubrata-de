# 🏆 Featured Projects

### 🎬 Cinema Audience Forecasting
**Time Series Prediction**

Built a time-series forecasting solution to predict daily cinema audience counts using booking data, theatre metadata, calendar information and historical booking trends.

---

### 🤖 Data Analyst Agent
**Automated Data Analysis & Visualization API**

An LLM-powered data analyst capable of receiving natural-language tasks with CSV, JSON or image inputs and autonomously performing data sourcing, processing, analysis and visualization.

---

### 🚗 ParkEase
**Smart Vehicle Parking Management System**

A full-stack parking management platform featuring role-based authentication, dynamic parking allocation, availability tracking, bookings, Redis caching and Celery-powered asynchronous tasks.

**Stack:** Flask • VueJS • SQLite • Redis • Celery

---

### 🏢 Placement Portal Application
**Role-Based Recruitment Management System**

A recruitment and placement management platform supporting Admin, Company and Student roles, including drive creation, applications, eligibility filtering, reminders, reports and CSV functionality.

**Stack:** Flask • VueJS • SQLite • Redis • Celery

---

### 🧠 Virtual Teaching Assistant for TDS

An AI-powered teaching assistant for the IIT Madras Tools in Data Science course, using course content and Discourse discussions to provide contextual answers and references through a REST API.

---

### 🏨 Hotel Booking Cancellation Prediction

A machine learning classification project designed to predict whether hotel bookings would be cancelled using structured booking information.

---

### 🏠 House Price Prediction

A machine learning regression project for predicting house prices using mixed categorical and tabular features.

---

### 🎥 Movie Review Sentiment Prediction

A multiclass sentiment-analysis model classifying movie reviews into **negative, neutral and positive** sentiment categories.
